# Angular In Action

Angular In Action is a **Lesson-by-Lesson Theory + Practical** Angular learning repository.

Each lesson is maintained in a **separate Git branch** and focuses on one particular Angular concept with **theory + practical coding exercises**.

The learning path starts with Angular fundamentals and gradually moves through core Angular concepts, HTTP, forms, authentication, testing, Bootstrap, and finally a complete Angular mini project.

# How to Learn

Start with **Lesson 1** and continue in order.

Open a lesson branch to find:

- Concept explanation
- Practical examples
- Step-by-step coding
- Runnable Angular code
- Lesson-specific README
- Exercises and demonstrations where applicable

Each branch is focused on one Angular concept so you can study, practice, and review topics independently.

# Angular 21

The repository focuses on **Angular 21** and uses practical examples to demonstrate how Angular concepts are applied while building applications.
